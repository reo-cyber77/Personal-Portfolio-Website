Get TaskBuddy

TaskBuddy is a simple to-do list for your Windows computer. Type what you need to do, tick it off when it’s finished and come back to it any time. No sign-up, no internet and nothing to learn first.

Download TaskBuddy (about 100 KB)

Before you start

TaskBuddy needs a free Microsoft component called the .NET 10 Desktop Runtime. If you’ve never installed it, open the Microsoft download page, choose x64 under “Run desktop apps” and run the installer once. Most Windows 10 and 11 computers use x64. Windows will also tell you if it’s missing when you open TaskBuddy.

Install it in four steps

  1. Click Download above. The file TaskBuddy.zip is saved in your Downloads folder.
  2. Open your Downloads folder, right-click TaskBuddy.zip, choose Extract All… and click Extract. A normal folder opens.
  3. In that folder, double-click TaskBuddy (it may show as TaskBuddy.exe). The window opens after a second or two.
  4. If Windows shows a blue box saying “Windows protected your PC”, click More info, then Run anyway. You only need to do this the first time.

Important: always extract the zip first. TaskBuddy won’t work properly if you run it from inside the zip file.

Tip: right-click TaskBuddy and choose Send to → Desktop (create shortcut) so you can open it with a double-click from your desktop.

How to use it

Add a task

Click the box that says “What needs doing?”, type your task and press Enter or click Add. The task appears in the list and the box clears, ready for the next one.

Mark a task as done

Click a task, then click Complete / Undo. It gets a ✓ and turns gray. Select it and click the button again to undo. You can also double-click a task.

Delete tasks

Click a task, then click Delete or press the Delete key. To remove everything you’ve finished, click Clear completed. TaskBuddy asks you to confirm first and never touches unfinished tasks.

Are my tasks saved?

Yes, automatically. Every time you add, complete or delete a task, your list is saved, so it’s waiting for you the next time you open TaskBuddy. Your list is kept in a small file called tasks.txt on your own computer. To see it, press the Windows key + R, type %AppData%\TaskBuddy and press Enter.

Common questions
  • Complete and Delete are grayed out. Click a task in the list first.
  • Clear completed is grayed out. You haven’t marked any task as done yet.
  • My tasks are missing. Make sure you’re signed in to the same Windows account as before.
  • Windows says .NET is needed. Install the .NET 10 Desktop Runtime from the “Before you start” section, then open TaskBuddy again.
